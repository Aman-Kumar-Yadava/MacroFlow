PROJECT: UNIVERSAL ANDROID MACRO RECORDER & PLAYER
Application name: MacroFlow — Touch Macro Studio
Package name: com.macroflow.touchstudio

YOUR ROLE
Act as a senior Android application architect, Kotlin developer, Android system integration engineer, gaming utility designer, and Material 3 UI/UX specialist.

Build a complete, functional, native Android application that allows users to create, manage, configure, and replay saved touch macros. The app should bring the convenience of floating gaming tools found in OnePlus Game Assistant, OPPO Game Assistant, and realme Game Assistant to compatible Android devices from different manufacturers.

Use the supplied screenshots as visual references for the macro editor, floating controls, recording workflow, repetition settings, playback speed, and button opacity. Create an original application with comparable functionality and interaction patterns. Do not copy OEM logos, proprietary assets, trademarks, or private system interfaces.

The goal is a working application, not just a UI mockup.

1. PROJECT OBJECTIVES
The application must:
- Allow users to create named macros.
- Record supported touch interactions using a technically valid Android implementation.
- Save recorded macros locally.
- Replay supported recorded gestures.
- Allow users to edit macro settings.
- Provide configurable repetition counts.
- Provide adjustable playback speed.
- Display a floating macro button over compatible applications.
- Allow users to access saved macros while another application is open.
- Provide a macro preview screen.
- Support editing, renaming, duplicating, and deleting macros.
- Persist macros between app launches and device restarts.
- Handle screen rotation, different screen resolutions, and aspect ratios.
- Work on compatible Android devices without requiring root access.
- Clearly explain device and Android-version limitations.

Prioritize correct gesture execution, data integrity, usability, and reliability over decorative animations.
